**(잡생각) 생산과 소비**

### 인간이 생존하기 위해서는 물질과 에너지가 필요함.
- 인간은 우주가 내재한 쟤료들을 소비하는 입장임.
- 우주에 있는 모든 물질은 물질과 에너지의 흐름에서 input, output 의 경계를 포함하고, 이를 소비라고 정의할 수 있음.
- 소비자라고 죄책감을 갖을 필요 없으며, AI도 우주의 물질과 에너지를 '소비'하는 것임.

### 무엇을 생산한다는 개념은 인간적인 개념임.
- '생산'이란 우주의 물질과 에너지가 흐르는 경로를 바꾸는 행위로 볼 수 있음.
- '생산'하지 않았을 때의 경로를 인위적으로 틀어서 '생산'하는 경로로 바꾼 것임.
- 그렇게 바뀐 경로가 어떤 미래를 야기하는 지에 주목해야함.
- '생산'된 물건과 서비스가 실제로는 인간의 행복도를 떨어뜨리고 출생인구를 감소시키는게 아닌지 고민해야함.

### 기술발전으로 인간의 삶은 더 나아졌나?
- 지능과 지식의 가격이 0에 수렴하고 있음.
- 재화 생산의 많은 부분이 자동화 되어가고 있음.
- 그런데 왜 대부분은 풍요를 느끼지 못하나?

### 의식주에 필요한 자원 자체는 이미 충분해보임.
- 선진국에서 얼어죽거나, 굶어죽거나, 집이 없어 죽는 경우는 거의 존재하지 않음.
- 마트나 백화점에는 재화가 차고 넘침.
- 화폐로 매겨진 부의 격차만 존재함.
