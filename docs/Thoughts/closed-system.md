**(잡생각) Closed system**

- 영화 매트릭스
   - matrix 안에서 나눈 대화
      - Neo: If I were you, I would hope we don't meet again.
      - Architect: We won't.
   - 하지만 Neo 가 machine world 를 직접 찾아가면서 다시 만나게 됨.
   - architect 는 matrix 의 system 안에서 만나지 않을 것이라고 확신함.
   - 단, 현실세계는 architect 의 영향/인지 바깥에 존재함.

- system 이 고정되면 그 system 으로 설명하지 못하는 현상을 포괄할 수 없음.
   - 모델링하고자 하는 대상이 있고, 이를 근사한 system 은 반드시 오차가 존재함.
   - 그 오차는 해당 system 이 설명할수 있는 영역 바깥에 존재함.

- 스스로 인식의 범주를 제한할 필요가 없음.
   - 특정 시점의 예측은 고정된 사고방식의 산물임.
   - 본인의 사고방식을 맹신하게 되면 현실과 인식의 오차를 줄이는 노력을 하지 못함.
   - 결국 그 사고 체계안에서만 살아가게 됨.
