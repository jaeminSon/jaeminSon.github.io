**(잡생각) Env ↔ Agent**

### Environment 의 전부를 Agent 가 모델링하지는 않음.
- Agent 가 받아들이는 정보를 생성하는 부분만 모델링됨.
    - e.g. 자율주행 자동차는 도로 및 도로 주변의 구조물, 자동차, 사람, 움직이는 물체 정도만 인식하면 됨.
- 모델링되는 부분과 실제 값 사이의 오차는 coding agent 를 통해서 빠르게 좁혀져 나갈수 있음.
    - $|Sim(A)-R(A)|<\epsilon$
- agent 가 필요한 simulator 는 빠르게 작성될수 있음.
    - robotics 도 정복될 날이 멀지 않았음.

### ASI 시대의 교육 혹은 education
- 가르치고 훈육하는 '교육' 은 frontier 사회에서는 사라질 것.
- 지식체계는 지식과 지능이 편입되면서 축척되어 나아감.
- 지식체계의 현실성은 별도의 문제임.
    - 종교가 반드시 과학적으로 타당할 필요는 없음.
    - 현재 우주를 근사하도록 지식체계를 구성하게 되면 지식체계의 수준은 우주에서의 관측값과의 오차로 평가될수 있음.
- ASI 보다 뛰어난 인간이 없다면, 새로운 지식/지능은 AI 가 모르는 상태에 존재함.
    - 지식체계의 지평을 넓히는 작업을 인간**학습자**가 할 수 있음.
    - 물론 ASI도 스스로 할 수 있음.
    - 인간 학습자가 contributer, maintainer 의 역할을 맡을수 있으며, pure explorer 의 역할을 맡게 됨.
        - 개인의 잠재력을 밖으로 끌어낸다는 의미의 **e** + **ducate** 의 의미가 더 커질듯함.
