# 외국 대학 학력 증명
- 학점은행 타전공으로 경영학 전공시 대부분의 기사 자격 응시 가능
- 외국 대학의 경우, 학부 졸업 증명 필요
    - 국가 평생 교육 진흥원에 직접 서류 전달해야함 (2026년 서울의 경우, 마곡역 근처)
    - 필요 서류
        - 대학교 졸업증명서 (교무과에 의뢰하여 우편으로 받음)
        - 학위증명서 (교무과에 의뢰하여 우편으로 받음)
        - 성적증명서 (교무과에 의뢰하여 우편으로 받음)
        - 인장증명서
            - 주한일본 대사관 직접 방문 필요
            - 졸업증명서, 학위증명서, 성적증명서 각각에 대해서 받음 (건당 15000원 현금 결재)
        - 주민등록등본
        - 출입국사실증명서
    - 주의 사항: 서류 접수 기간 정해져 있음 (2026년은 10월 1일 ~ 10월 8일 사이)
