### 서명 받기
- 답례품: 10L 쓰레기 봉투 2장
- 부재중인 세대: 남은 청접장 봉투(총 43장)에 메모 붙이고 쓰레기 봉투 2장 넣어서 초인종 위에 올려둠.

```
안녕하세요, xxx동 xxx호의 입주 예정자입니다. 저희 가족이 입주 전 간단한 내부 인테리어 공사(시스템에어컨, 신발장 타일, 도배, 마루, 중문, 붙박이장)를 진행하게 되었습니다. 공사 기간 중 다소 소음 발생이 예상되어 ( 9월: 9,11,14,15,16,21,30일, 10월: 1일) 직접 찾아뵙고 인사드리려 했으나, 부재중이셔서 글로 대신 양해를 구합니다. 약소하지만 이웃 세대에 불편을 드려 죄송한 마음을 담아 종량제 봉투를 함께 남깁니다. 공사가 안전하고 신속하게 마무리될 수 있도록 최대한 주의하겠습니다. 불편한 점 있으시면 언제든지 010-xxxx-xxxx 로 연락주시기 바랍니다.
```
