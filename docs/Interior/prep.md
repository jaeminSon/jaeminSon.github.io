# 참고 (lxzin 시공 과정 예시)
- 걸레받이 철거 후, 마루 시공시 먼지가 많이 날리고, 걸레받이 마감이 더 수월하여 도배보다 먼저하는 경우가 많다고 함.

# 기타
- 전기-스위치의 위치는 미리 알아두면 편함.
- 전등의 위치를 먼저 잡고 선을 빼놓아야함.
- 실크는 쉽게 뜯을수 있어서 도배 시공에 포함됨.
    - 합지는 뜯을수 없다고 함.
- 몰딩, 걸레받이가 짧아지면, 퍼티작업 (평탄화) 필요하고 인력 1명 추가됨.
- 샌딩비용 평당 2만4천원 (우리의 경우 50~80 으로 예상했는데, 부분만 해서 철거 포함 40만 지불)
- 필름시 신발장이 중문에 가려지면 가려지는 부분이 작업이 어려움.
- 걸레받이, 몰딩은 원하는 색으로 맞춰서 구매해두면 색상 이슈가 없음.
